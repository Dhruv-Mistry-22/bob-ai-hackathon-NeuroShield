## PATH 1 — EDA 🔍

**Goal:** Understand the data before modeling.

### 1.1 Data structure

Check:

* rows
* columns
* datatypes
* missing values
* duplicates
* timestamp frequency
* unique zones
* unique assets
* unique resources

### 1.2 Grid behavior

Analyze:

```text
Demand
Temperature
Renewable generation
Reserve margin
Grid frequency
Transmission flow
Transmission capacity
Curtailment
```

Questions:

> When is demand highest?

> What does a normal day look like?

> When does renewable generation peak?

> When does transmission become stressed?

### 1.5 Curtailment analysis

This is extremely important for our project.

```text
Transmission flow
       ↓
Transmission utilization
       ↓
Renewable available
       ↓
Renewable dispatched
       ↓
Curtailment
```

We want to prove:

> **High transmission utilization → renewable curtailment**

The current dataset is especially useful here because the reported curtailment-event transmission utilization is ~97%.

This tells us whether the synthetic events have **learnable signatures**.

# PATH 2 — Feature Engineering ⚙️

After EDA, create the features.

We don't want every raw column going blindly into the model.

Example:

```text
Raw data
   ↓
Time features
   ├── hour
   ├── day_of_week
   ├── month
   └── holiday
   ↓
Lag features
   ├── demand_lag_1
   ├── demand_lag_4
   └── demand_lag_96
   ↓
Rolling features
   ├── demand_mean_1h
   ├── demand_mean_6h
   └── demand_std_6h
   ↓
Weather features
   ├── temperature
   ├── humidity
   └── etc.
   ↓
Grid features
   ├── transmission_utilization
   ├── reserve_margin
   └── renewable_share
```

Result:

```text
ML-ready dataset
```

```text

```



```json
{
  "demand_risk": 0.87,
  "renewable_forecast_mw": 1450,
  "transmission_utilization": 0.97,
  "curtailment_risk": "HIGH",
  "asset_alert": "SOLAR_07",
  "root_cause": "inverter_fault",
  "battery_action_mw": 250,
  "hydro_action_mw": 150,
  "dr_action_mw": 100
}
```

Then the LLM converts this into:

> **Operator Brief:** High grid stress is expected around 18:00. Transmission loading is approaching its limit while renewable generation remains high. SOLAR_07 is showing an independent inverter fault. Discharging the battery and increasing hydro and demand response can reduce expected renewable curtailment.
